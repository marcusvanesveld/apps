Getting started

I chose a folder and search finds nothing

Search looks inside what people say, so a film has to be indexed before it can be searched. Films that carry subtitles are indexed automatically the moment they are added. For the rest, use File › Transcribe Library.

Transcription runs on your own Mac and takes a while on a large library. You can keep watching while it works, and it picks up where it left off.

Which languages does transcription understand?

English. It uses the speech recognition built into macOS, and ViddyGrid currently asks it for English only. Subtitles in other languages are still indexed as they are.

The first transcription wants a download

That is macOS installing its English speech model, once, if your Mac does not already have it. It comes from Apple. Nothing about you or your files is sent — see the privacy policy.

Playback

A file will not open

ViddyGrid decodes MKV, AVI, Xvid, MPEG-2, VOB, WebM and the usual modern formats itself, with no codec pack. If a file still refuses, the status line names the reason, and View › Diagnostics gives the full decoder error. Send me that error and the file's format and I will tell you whether it is fixable.

One common cause is a file that has moved or been renamed since it was added to the library.

Does ViddyGrid change my video files?

No, and it cannot. macOS grants it read-only access to the folder you choose. It cannot write to, rename or delete anything in it, and there is no conversion or re-encoding step anywhere in the app.

Where do my transcripts live?

In ViddyGrid's own container on your Mac, under ~/Library/Containers/. They are never uploaded. Removing the app removes them.

Requirements

macOS 26 or later, on Apple silicon. Transcription uses the on-device speech recognition that ships with macOS.
