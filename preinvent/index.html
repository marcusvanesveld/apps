Preinvent

A Mac app and a command line · free

Preinvent answers one question before you write code: did someone, you or the world, already build this?

One query searches your own repo folders, your GitHub stars, your installed tools and eleven public registries, and returns one ranked list with the source of every row. No account, no API keys, no server of mine.

Install

Mac app

Preinvent.app, signed and notarised. It already contains the pre command line. Open the disk image and drag Preinvent to Applications. macOS 26 or later.

Download Preinvent 0.1.0 (DMG)

Command line, with the agent skill

pre plus the skill that tells a coding agent when and how to use it. Unpack the archive and run the installer. It puts pre in ~/.local/bin and writes the skill to ~/.claude/skills/preinvent/. Already have the app? Run install_cli.sh /Applications/Preinvent.app/Contents/Resources/pre instead.

Download pre 0.1.0 (Apple silicon)

tar -xzf precli-0.1.0-arm64-apple-darwin.tar.gz && ./install_cli.sh

Mac app and iOS app

The iOS app is a separate install and does not need the Mac. It is not available yet.

Checksums for every file: SHA256SUMS.
