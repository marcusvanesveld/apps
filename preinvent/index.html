Preinvent

Find what already exists before you build it.

Describe what you want to build, in plain words. Preinvent searches your own repos, your GitHub stars and the public registries, and returns one ranked list of what is already out there.

Download for Mac

Free. Version 0.1.0, 24 MB. macOS 26 or later, Apple silicon. Signed and notarised by Apple.

Three ways to get it

Mac app

The full app. The pre command line is inside it.

Download the DMG

Open the DMG and drag Preinvent to Applications.

iPhone app

The whole search engine runs on the phone. No Mac and no server needed.

Join the TestFlight beta

The link opens once Apple has reviewed the first beta.

Command line

pre for the terminal, plus a skill that tells a coding agent when and how to use it. The installer puts pre in ~/.local/bin and the skill in ~/.claude/skills/preinvent/.

Download pre (Apple silicon) 
tar -xzf precli-0.1.0-arm64-apple-darwin.tar.gz
./install_cli.sh

Already have the Mac app? Run install_cli.sh /Applications/Preinvent.app/Contents/Resources/pre instead.

What it does

  • One query searches your repo folders, your GitHub stars, your installed tools and public sources, from GitHub, GitLab and npm to Artifact Hub and the ESP Component Registry.
  • You get one ranked list. Every row names its source, with license and upkeep where the registry reports them.
  • Planning a whole system? List its parts in one file, and pre tetris returns a shortlist of existing projects for each part. Near misses are labelled, not dropped.

Privacy

No account, no API keys, no server of mine, no chat model and no cloud AI. Ranking runs on your device. The privacy page lists every host a search can reach.
