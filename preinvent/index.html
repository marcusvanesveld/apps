Preinvent

Don't reinvent the wheel.

Find what already exists before you build it. Describe what you want to build, in plain words. Preinvent searches your own repos, your GitHub stars and the public registries, and returns one ranked list of what is already out there.

No account, no API keys, no server of mine.

One query

Searches your repo folders, your GitHub stars, your installed tools and public sources, from GitHub, GitLab and npm to Artifact Hub and the ESP Component Registry.

One ranked list

Every row names its source, with license and upkeep where the registry reports them.

Whole systems

List its parts in one file, and pre discover --catalog returns a shortlist of existing projects for each part. Near misses are labelled, not dropped.
