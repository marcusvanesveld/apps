Preinvent

A Mac app, an iPhone app and a command line · free

Preinvent answers one question before you write code: did someone, you or the world, already build this?

One query searches your own repo folders, your GitHub stars, your installed tools and public sources, from GitHub, GitLab and npm to Artifact Hub and the ESP Component Registry. It returns one ranked list with the source of every row, plus license and upkeep where the registry reports them. Describe a whole system and pre tetris gives a ranked bench for each part, near misses labelled instead of dropped. No account, no API keys, no server of mine, no AI model calls.

Install

Mac app

Preinvent.app, signed and notarised. It already contains the pre command line. Open the disk image and drag Preinvent to Applications. macOS 26 or later, Apple silicon.

Download Preinvent 0.1.0 (DMG)

Command line, with the agent skill

pre plus the skill that tells a coding agent when and how to use it. Unpack the archive and run the installer. It puts pre in ~/.local/bin and writes the skill to ~/.claude/skills/preinvent/. Already have the app? Run install_cli.sh /Applications/Preinvent.app/Contents/Resources/pre instead.

Download pre 0.1.0 (Apple silicon)

tar -xzf precli-0.1.0-arm64-apple-darwin.tar.gz && ./install_cli.sh

iPhone app

The whole search engine runs inside the app, so it needs no Mac and no server. It is on its way through TestFlight; the invite link appears here once Apple has reviewed the beta.

Preinvent for INFO

Voor collega’s van INFO is er een eigen editie. Het is dezelfde zoekmachine, zonder de video- en YouTube-functies. De bibliotheek begint leeg, dus je eigen sterren en mappen zijn van jou. Elke rij toont waar hij vandaan komt, en rijen uit GitHub, npm en crates.io ook licentie en onderhoud. Een bench exporteer je direct als Research spec of als ADR in MADR-formaat.

Mac-app

Preinvent for INFO.app, ondertekend en genotariseerd door Apple. Open het schijfbestand en sleep de app naar Programma’s. Vereist macOS 26 of nieuwer op Apple silicon.

Download Preinvent for INFO 0.1.0 (DMG)

Command line voor je agent

pre met de skill voor Claude Code. Pak het archief uit en start de installer. Die zet pre in ~/.local/bin en schrijft de skill naar ~/.claude/skills/preinvent/.

Download pre for INFO 0.1.0

tar -xzf precli-info-0.1.0-arm64-apple-darwin.tar.gz && ./install_cli.sh

iPhone-app

Volgt via TestFlight. De uitnodigingslink staat hier zodra Apple de beta heeft goedgekeurd.
